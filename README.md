# Respira

Prototipe interaktif Respira V2 (desain *Premium Wellness*): kualitas udara real-time, rekomendasi kesehatan keluarga, rute udara bersih, laporan Lens dengan verifikasi AI, dan gamifikasi **Respira Air Quest**.

Situs statis tanpa build: buka `index.html`, atau deploy di Vercel (Framework Preset: **Other**).

## Alur demo
1. Splash → onboarding (3 layar, bisa digeser) → daftar 3 langkah → akun dibuat
2. Home: misi "Cek kualitas udara" otomatis selesai (+10 XP) dan lencana **Air Aware** terbuka
3. Map: ketuk 5 titik SPKU → klaim misi jelajah (+15 XP)
4. Rute aman: pilih tujuan → mode & preferensi → bandingkan 3 rute → navigasi → perjalanan selesai (+30 XP)
5. Lens: tahan tombol kamera → verifikasi AI (percobaan pertama gagal, kedua lolos) → kirim → tervalidasi (+50 XP, lencana **Eco Reporter**) → **naik ke Level 3 Air Guardian**
6. Profile: edit profil, tambah anggota keluarga, pengaturan, bantuan, progres & lencana

Progres tersimpan di browser. **Pengaturan → Keluar** mengulang demo dari awal.

Versi sebelumnya tersimpan di branch `v1`.
